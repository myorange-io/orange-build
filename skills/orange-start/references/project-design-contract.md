# 조직 디자인과 세 단계 구현 계약

프로젝트의 AGENTS.md / CLAUDE.md, TEAM.md, 루트 DESIGN.md를 먼저 읽습니다. 조직 공통 규칙과 프로젝트별 선택을 구분하고 설계·구현·검수에 같은 기준을 전달합니다. 디자인이 없는 프로젝트도 기본 디자인으로 진행할 수 있습니다.

## 명시적인 단계 요청

App 요청의 `implementation_stage: design | build | verify` 또는 사용자가 명시한 세 단계 요청이 있으면 해당 단계만 실행합니다. 이 추가 메타데이터는 `contract_version: 2` 원본 기획서와 STEP·REQ·TEST 계약을 바꾸지 않습니다.

- design: 역할 소개 → 팀 다이어그램 → 첫 작은 완성의 화면 설계. `../../orange-design/references/design-recommendations.md`의 원칙을 사전 설계에 확장해 실제 분석 링크가 확인된 사례를 최대 2개 추천합니다. 승인된 DESIGN.md와 충돌하지 않는 화면 구성만 비교합니다. 분석 페이지를 확인할 수 없으면 검색 링크와 한계를 밝히고 기본 시안을 제시합니다.
- 첫 구현 전 주요 화면의 간단한 시안을 브라우저에서 보여줍니다. 화면 없는 ai_skill / automation은 실행 흐름과 출력 예시로 대신합니다. 시안은 확인용 결과이며 실제 기능 구현과 구분합니다. 이 요청은 필요한 설계 기록과 임시 시안을 만드는 범위만 허용합니다.
- 사용자가 시안을 선택한 뒤 출처·고정 기준·프로젝트별 결정을 DESIGN.md에 기록하고 역할·담당 파일·의존 관계·완료 조건을 TEAM.md에 기록합니다. 선택 전 기능 코드와 조직 고정 기준을 변경하지 않습니다.
- build: 같은 대화에서 합의한 범위·시안·TEAM.md·DESIGN.md를 확인합니다. 합의한 작은 완성의 구현 요청은 해당 범위의 구현과 명시된 팀 실행 승인으로 적용합니다. 합의가 없으면 현재 STEP 범위를 확인하고 기다립니다. 전체 기획서를 한 번에 구현하지 않습니다.
- verify: 현재 STEP의 TEST와 실제 결과, DESIGN.md 준수 여부를 확인하고 실패를 수정합니다. 사용자가 현재 결과를 확인한 뒤 다음 개선을 고르면 다음 STEP의 세 단계를 반복합니다.

## 역할과 실제 모델

- 사용자나 프로젝트 TEAM.md가 명시한 혼합 모델 계약이 있으면 그 모델·추론 수준을 우선합니다. 기본 호스트 모델 지침으로 이를 조용히 바꾸지 않습니다.
- Codex: 총괄·설계·통합·검수 GPT-6.1 Sol / Medium / Standard, 필요한 구현 작업자 GPT-6 Luna / High입니다.
- Claude: 총괄·설계·통합·검수 Opus 5.5 / Medium, 필요한 구현 작업자 Sonnet 5.5 / Medium입니다.
- Codex 작업자는 fork_turns="none"으로 필요한 맥락만 전달하고 model="gpt-6-luna", reasoning_effort="high"를 명시합니다. 전체 대화 fork로 부모 모델을 상속하지 않습니다.
- 역할 이름과 담당 파일은 과제마다 정합니다. 필요한 작업자만 만들고 하위 에이전트의 추가 위임을 금지합니다. 독립 검수는 위험·복잡도상 필요한 경우만 추가합니다.
- 파일의 모델 표기만으로 실행 확인을 대신하지 않습니다. 실제 모델 기록을 확인하고 사용할 수 없는 모델은 사용자에게 알립니다.
- 만드는 팀과 완성된 프로그램의 runtime AI 처리 방식은 구분합니다. 원본 executionMode가 rules / single_call이면 내부 멀티에이전트를 추가하지 않습니다.

## 반복과 변경

첫 시안 선택 이후 디자인을 재사용합니다. 새 화면 유형이나 방향 변경이 필요할 때만 다시 비교합니다. 조직 디자인이 나중에 준비되면 영향과 변경 범위를 설명하고 승인 후 적용하며 기존 DESIGN.md를 자동 덮어쓰지 않습니다.

명시적인 사전 설계 요청 없이 기본 orange-start 실행에서 디자인 picker를 강제하지 않습니다. 완성 후 디자인 개선 스킬 orange-design의 최종 검증 게이트는 그대로 유지합니다.
